# 趋势分区 — 测试方案草案

### 分区与周期
| 字段 | 内容 |
| --- | --- |
| **ID** | TC-TRENDUI-001 |
| GIVEN | 健康报告及本地计划/体重 |
| WHEN | 查看三个分区 |
| THEN | SHALL内容正确归属、无重复全量堆叠，图表与回顾分别标明真实周期 |
| 验证 | 分区/指标纯映射测试＋UI截图/实际导航 |

### 状态保留
| 字段 | 内容 |
| --- | --- |
| **ID** | TC-TRENDUI-002 |
| GIVEN | 各分区不同选择和滚动位置 |
| WHEN | 分区/Tab切换及刷新 |
| THEN | SHALL保留会话分区、筛选及适用锚点，不发起额外读取或写入 |
| 验证 | 纯状态模型测试＋UI往返和请求/写入观察 |

### 空态与本地记录
| 字段 | 内容 |
| --- | --- |
| **ID** | TC-TRENDUI-003 |
| GIVEN | 没有健康报告，有/无本地体重及计划 |
| WHEN | 进入各分区并记录体重 |
| THEN | SHALL独立显示本地能力，缺健康不给默认正常值，kg与周均门槛保持 |
| 验证 | 既有Planning/Weight回归＋无健康UI流程 |

### 来源与可访问性
| 字段 | 内容 |
| --- | --- |
| **ID** | TC-TRENDUI-004 |
| GIVEN | 演示弹窗、日内详情、辅助字体或旧报告 |
| WHEN | 切换来源/清除、滚动或往返详情 |
| THEN | SHALL失效旧编辑且不跨来源保存，保留演示/过期说明，内容可读且不被顶部遮挡 |
| 验证 | 来源防护回归、Apple编译及真实字体/滚动/弹窗交互分别记录 |
