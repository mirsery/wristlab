# EXP-20261024-015 展示时钟与真实操作入口必须独立验证

- lifecycle_state: discovered
- category: runtime_deviation
- severity: medium
- language: swift
- change: 2026-10-24-phone-today-care
- provenance: readonly-review-and-synthetic-tests

展示层不能把系统调度时间或上次激活时间作为真实 now 的下限：墙钟回拨后，max(context.date, resumedAt) 会掩盖 effectiveAt 位于真实未来的情况。TimelineView 仅作触发器，每次渲染读取真实 Date；演示仍显式使用冻结 asOf。纯展示测试覆盖前后边界、回拨与未来观测；不以此声称系统时间调整时的调度精度已经实机验证。

隐藏子元素语义后的 NavigationLink 应显式保留按钮语义。仅凭模型可访问标签测试不足以证明入口能被发现；本轮旧生产电量卡 RED（仍显示分数）与新卡真实 UI 查找暴露了按钮语义丢失，补 isButton 后聚焦用例通过。

UI 过期测试应在页面就绪后由合成宿主显式启动期限，避免把启动耗时当业务失败；两类时间必须使用不同合成值并各自断言。List 的负断言需配合纯领域有效/过期贡献矩阵，防止行虚拟化假绿。并行跑同一宿主/模拟器会相互干扰，构建及测试探针须串行执行。自定义模拟器名称不能用 name 包含 iPhone 筛选，应检查 deviceTypeIdentifier。

仅记录本地合成测试与代码评审经验；不含真实健康数据、不上传社区、不修改全局记忆。

后续诊断：前后台用例不能只发 Home 再 activate 就认为发生了后台转换。本机所选 Duo 及单屏 mini 在 Home 后均未满足后台前置条件，合成 PID/期限/phase 保持原值。必须先断言 app.state 为 runningBackground/挂起，再验恢复；仅 4 秒断言失败不能证明违反原 30 秒显示上限。未证实的 task 生产替换已撤回，保留失败报告并按预授权阈值降级，下一步测试驱动修正仍待执行。

恢复验证：用户授权继续仅排查测试环境后，改用激活系统设置并断言真实后台/返回前台，不修改任何系统设置；聚焦 1/1 与完整关怀 10/10 均通过。断言直接查询原按钮，避免滚动 helper 延后计时。证据只证明真实后台返回后正确显示过期，不独立证明期限恰在后台跨过。产品仍使用原 TimelineView+Date，未用改产品迎合错误驱动。
