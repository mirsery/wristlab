# EXP-20261024-016 无 Sendable 标注的 ObjC 回调不能接 MainActor 闭包字面量

- lifecycle_state: discovered
- category: runtime_deviation
- severity: high
- language: swift
- change: 2026-10-24-watch-refresh-exit
- provenance: device-crash-symbolication-and-synthetic-tests

Swift 6 模式下，`@MainActor` 方法里写给 ObjC API 的闭包字面量会继承 MainActor 隔离；若该参数缺 `NS_SWIFT_SENDABLE`（如 `WCSession.sendMessage` 的 reply/error），且以 `@preconcurrency import` 引入，编译器不报错，只在闭包入口插入动态隔离检查。框架在后台队列回调时 `_dispatch_assert_queue_fail` → EXC_BREAKPOINT，进程直接退出。症状是「点刷新后闪退」，模拟器单测很难复现。

检测：崩溃栈出现 `closure #N in <MainActor 方法>` + libswift_Concurrency + `_dispatch_assert_queue_fail`；对照 SDK 头文件确认 block 参数有无 `NS_SWIFT_SENDABLE`（HealthKit 查询回调已标注，WatchConnectivity 未标注）。

修复模板：在非隔离上下文构造 `@Sendable` 处理闭包（只取 Sendable 值），再 `Task { @MainActor in ... }` 回主线程；调用点传函数值而非闭包字面量，并用 grep 守卫防止回退，因为该回退不会产生编译告警。只记录合成测试与符号化结果，原始崩溃报告不入库。
