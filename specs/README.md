## 追溯规则

PR写验收ID与SCN号；改参数同步模型版本、金例与解释；改源/时区/历史需传播后续基线和电量失效。外部来源保留核对日期，旧说明不作为平台保证。

S0已有双端模拟器构建和容器基础测试，不覆盖新业务。实现顺序以007为准，先纯业务、再数据持久化/双端界面。
