# iCloud与数据中心 — Gate2测试计划

### 账户状态
| 字段 | 内容 |
| --- | --- |
| **ID** | TC-CLOUD-001 |
| GIVEN | 未登录/受限/可用/暂不可确定/应用缺配置 |
| WHEN | 查看我的、回前台或检查账户 |
| THEN | SHALL中性区分状态、不显示虚构身份、不将账户可用视为同步成功；未配置不发无效请求 |

### 上传白名单
| 字段 | 内容 |
| --- | --- |
| **ID** | TC-CLOUD-002 |
| GIVEN | 界面四偏好、健康/计划/体重等合成数据及演示模式 |
| WHEN | 启用同步、序列化或本地编辑 |
| THEN | SHALL默认关闭且开启前说明范围，只允许四个界面字段及版本元数据，演示不上传，健康数据绝不进入载荷 |

### 首次恢复与冲突
| 字段 | 内容 |
| --- | --- |
| **ID** | TC-CLOUD-003 |
| GIVEN | 云端已有偏好/无记录/未知schema或另一设备并发修改 |
| WHEN | 新机启用、选择恢复或上传 |
| THEN | SHALL先读取且选择前不覆盖，使用服务端版本校验，冲突需重新确认，不用本地时间戳强制覆盖 |

### 账户隔离
| 字段 | 内容 |
| --- | --- |
| **ID** | TC-CLOUD-004 |
| GIVEN | A账户未完成请求/队列或暂时离线 |
| WHEN | 收到账户变更、切B、关闭同步或收到晚回调 |
| THEN | SHALL先失效旧generation并隔离账号环境，不把A数据写B，身份未确定不猜迁移，旧回调不改新状态 |

### 离线重试与可读范围
| 字段 | 内容 |
| --- | --- |
| **ID** | TC-CLOUD-005 |
| GIVEN | 离线、配额/认证/服务器失败、应用重启或新机健康尚未到达 |
| WHEN | 编辑/重试/恢复 |
| THEN | SHALL保留本地且明确待同步，成功时间仅确认后更新，队列只在原账户恢复；健康缺失不补分，不声称体重目标已恢复 |

### 清除与删除
| 字段 | 内容 |
| --- | --- |
| **ID** | TC-CLOUD-006 |
| GIVEN | 本地/云端偏好、其他设备旧副本及未完成任务 |
| WHEN | 关闭、清本机或确认删云端 |
| THEN | SHALL区分各操作，不删除健康原始；云删除确认前不报成功，删除标记阻止旧副本静默复活，重新上传需明确确认 |

单元测试：Foundation白名单、状态机、版本/generation和错误映射，用合成账户及模拟CloudKit适配器可控暂停/失败/冲突；集成：偏好落盘、outbox重启与界面实际接线，不将模拟后端当真实云验证。
平台：scripts/check.sh、scripts/build-apple.sh、STDD结构/失败模式和git diff --check。实际CloudKit Development/Production配置、私有库读写、两台同账户设备恢复、切账户隔离、删除不复活、未登录/离线、辅助字体/手机安全区分别验收；缺设备/签名就明确未完成。
不打印真实Apple账户、健康值或CloudKit记录内容，不用真实资料作fixture，不提交签名配置。Gate2待确认，本阶段不实现、不联网上传、不安装；Gate3不自批。
