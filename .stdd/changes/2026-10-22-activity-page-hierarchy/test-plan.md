# 活动页整合 — Gate 2 测试方案草案

| TC | 场景 | 计划验证 |
| --- | --- | --- |
| 001 | 今日优先与模式准确 | 固定分析时钟，手动、自动、明日生效、暂停、无计划的只读投影测试；UI检查今日/周摘要/详情顺序与唯一管理入口 |
| 002 | 管理入口完整且不静默写入 | UI依次进入自动/手动分段、预览/取消/保存、切回手动、周反馈与重读；确认浏览不变revision，取消不改计划，所有旧动作仍可达 |
| 003 | 证据与人工独立 | 回归健康新增/删除、人工完成/休息、缺失、旧字段、原目标保留；UI检查两类状态并列及解释可达 |
| 004 | 详情与可访问性 | 默认/最大辅助字体及窄屏；负荷/区间/记录明细可达，覆盖度和编号含义保留；Tab往返、刷新、演示切换、长中文、顶部/底部滚动和手机安全区 |

### 今日模式
| 字段 | 内容 |
| --- | --- |
| **ID** | TC-ACTUI-001 |
| GIVEN | 已有/空计划及未来生效版本 |
| WHEN | 查看活动页 |
| THEN | SHALL按分析日期显示实际模式，今日优先 |

### 管理操作
| 字段 | 内容 |
| --- | --- |
| **ID** | TC-ACTUI-002 |
| GIVEN | 自动/手动管理页 |
| WHEN | 浏览、取消或明确保存 |
| THEN | SHALL保留所有旧动作，浏览取消不写入 |

### 独立状态
| 字段 | 内容 |
| --- | --- |
| **ID** | TC-ACTUI-003 |
| GIVEN | 人工完成/休息与健康记录 |
| WHEN | 查看任务与进度 |
| THEN | SHALL独立表达，不补缺失为零 |

### 可访问详情
| 字段 | 内容 |
| --- | --- |
| **ID** | TC-ACTUI-004 |
| GIVEN | 辅助字体、窄屏、旧报告与演示 |
| WHEN | 导航、滚动与切换来源 |
| THEN | SHALL文字可读，详情可达，不沿用旧表单 |

映射：四TC一一对应SC-ACTUI-001–004，关联P-011、P-013/014、P-017–019；不更改原验收边界。实现时模型部分测试先行，SwiftUI交互证据另行记录，未运行的不标通过。
