# EXP-20261024-017 SwiftUI 双列卡片与隐藏导航栏的布局陷阱

- lifecycle_state: discovered
- category: ui_layout
- severity: medium
- language: swift
- change: 2026-10-24-phone-care-layout
- provenance: simulator-ui-tests-and-screenshots

`LazyVGrid` 的 `GridItem` 默认行内垂直居中，不同文本长度的卡片会上下错位；需要等高时用 `HStack(alignment: .top)` + `.fixedSize(horizontal: false, vertical: true)`，子视图 `frame(maxHeight: .infinity)`。贴底元素用 `frame(maxHeight: .infinity, alignment: .bottom)`，不要用 `Spacer(minLength: 0)`：后者在 VStack 中多占一个 spacing，会让 ScrollView 中自然高度的同款卡片变高。定高行内的 Text 需纵向 `fixedSize` 防压缩。

隐藏导航栏的滚动页没有状态栏背板，iOS 26 软边缘只做模糊，文字会叠在时钟后面；用零高度 `safeAreaInset(edge: .top)` + 同色 `background(ignoresSafeAreaEdges: .top)` 遮挡。验证用截图像素采样，并先断言已有内容位于采样带下，否则可能假绿。XCUITest 会列出带 identifier 的 `accessibilityHidden` 容器，`exists` 不能证明 VoiceOver 隐藏；透明背景的元素 frame 会塌成 0 高。只用合成数据和模拟器截图，不复制真机截图数值。
