# 十四类失败模式核对

此表是本轮逐项语义检查，不替代实际测试报告。CLI ci check-failures 已执行，因上游只扫描 Python 的 TC 实现，报告 Swift 覆盖 0/6；AND 按整文件累计为 15、能力提取为空、canonical 锚点路径不识别也已复核，不修改 vendor、不把 CLI 结果称全绿。

| 类别 | 实际检查与结论 |
|------|----------------|
| (a) 幻觉行为 | 核对原 MetricTier、MetricExplanation、isStale；没有引入竞品或医学阈值，真实 0 和缺数分开。 |
| (b) 范围蔓延 | 逐文件审查仅新增手机展示/详情及其合成测试、流程文档；其他未提交改动保留，Watch/读取/同步不扩展。 |
| (c) 级联错误 | Core 纯展示与 SwiftUI 单向连接；MetricDetailView 平移后只有一份定义；共享 ScoreRing/SmallMetricCard 未改。完整回归见最终日志。 |
| (d) 上下文丢失 | 当前 change 记录实际 Gate 1/2 与本轮长程授权；未继承此前授权，Gate 3 不自行批准。六场景/六 TC 对照。 |
| (e) 工具误用 | 模拟器命令仅 simctl，测试脚本过滤 iPhone 模拟器；新建隔离 mini 用于正式演示冒烟，未操作 devicectl/真机。修正测试并发干扰后串行执行。 |
| (f) 运行时行为偏差 | 三路评审发现真实时钟回拨缺陷已修复，显式 Date/演示时钟不加 max 下限；补未来观测和回拨测试。 |
| (g) 管线断链 | 新关怀 UI 脚本接入 build-apple.sh；旧生产卡片 RED 与新生产组件 GREEN 分别记录，不把未实际验证的旧链路当 RED。 |
| (h) 内容质量偏差 | 用图标配状态/原因，不靠颜色，不推算心情；模型/时间/来源在详情可追溯，未知来源不伪造。最终窄屏最大字体及长原因截图已人工核对。 |
| (i) 指令衰减 | iCloud 保持关闭，无新增权限、依赖、通知或真机安装；无 Git 提交/分支/标签/推送和第三方经验上传。 |
| (j) 覆盖真空 | 九项新 Core 测试及生产 UI 用例对应六 TC；详情两类时间分开输入/断言，贡献正反断言防止 List 虚拟化假绿。未启用行/分支覆盖率，不能给出百分比。 |
| (k) 契约断层 | 单能力复用原 ComplicationMetric 路由与 MetricEstimate，不更改数据结构、评分或同步 schema；默认缺失估算与原详情兼容。 |
| (l) 锚定缺失 | canonical L2 锚定现有 MetricExplanation、MetricTier、PhoneDashboardView；未引用 Watch 快照 TTL，只复用纯压力分段函数。 |
| (m) Agent CP 失败 | 三路只读评审及恢复后增量复核均返回，代码问题关闭，测试缺口已加固。CP-1–6 对应最终 254 Swift、10 关怀 UI 与完整 App 冒烟等证据见 test-report；Gate 3 仍由用户确认。 |
| (n) 跨系统不一致 | 无新增跨系统接口；手机以指标有效期、Watch 保留自身快照时限，差异明确。实际双端同步、真实健康和完整 VoiceOver 不在本轮验收。 |
