# 001 产品与业务闭环

规格状态：已定义 business-v1，2026-10-20。运行状态：领域与双端代码已进入实现；测试及真机范围见[验证记录](../docs/validation.md)。

## 目标

自用安装在iPhone及配对Apple Watch，本地读取记录，解释今天的状态和活动趋势。术语见[词汇表](../GLOSSARY.md)，参考边界见[000](000-reference-behavior.md)。所有估算是实验模型；建议是相对历史的参考区间，不是训练处方。

```text
主动开启读取 → 历史/增量 → 校验去重和选源
  → 睡眠与基线 → 准备度/压力/运动负荷 → 电量重放
  → 原子提交报告 → 手机解释/历史 → Watch与组件快照
```

## 用户业务

| 情景 | 成功结果 | 未满足条件 |
| --- | --- | --- |
| 首次打开 | 默认真实空状态，可主动进入独立演示 | 不预填健康分数 |
| 起床 | 主睡眠、准备度及与基线比较 | 显示缺少当前输入或实际有效历史天数 |
| 白天 | 最近压力、电量、时间和来源 | 过期历史与当前值分开，不伪造连续测量 |
| 看睡眠 | 主睡眠/小睡、阶段、7日债务与规律性 | 有时长无阶段仍展示时长，未知不当0 |
| 运动后 | 负荷、区间、当天输出与参考目标 | 低覆盖只给已观测下界 |
| 数据补录/删除 | 修订影响日及后续依赖 | 失败保留旧报告并标待更新 |
| 手机离线 | Watch使用最后快照 | 展示过期与等待同步，不独立生成分数 |

v1范围：只读数据、来源管理、三项核心估算、睡眠汇总、已有运动分析、日内/7日趋势（long-trends扩展为7/30日与近7日回顾）、本地清除、同步与组件。42日负荷趋势为后置能力。

范围外：账号/订阅、AI、饮食识别、训练录制/课程、社交、身体年龄、云服务和App Store上架。

设置：固定分析时区、各类来源优先级、睡眠目标（默认480分钟，240–720且步长15）、训练模式（轻松/维持/发展）、自行输入MHR、演示入口、刷新、清派生缓存、停止读取并清应用数据。睡眠目标是偏好，不是医学推荐。

## 状态契约

来源：demo/healthKit，缓存与同步隔离。可用性：available/calibrating/insufficientData/unsupported/failed。数据质量：有值时complete/partial，表示模型输入齐全程度，不表示科学有效。报告阶段：provisional/settled；稳定报告仍可因迟到数据产生新revision。时效性独立叠加，重新打开或重算不刷新原始采样年龄。

必要当前输入缺失→insufficientData；当前输入齐但历史不足→calibrating并列实际天数；满足全部必要条件→available。请求或刷新错误是独立操作状态；有旧结果时不覆盖旧报告。空HealthKit读取不推断denied。

## 验收标准

- P-001：双端演示明确，未知为“暂无数据”；现有骨架只覆盖基本展示。
- P-002：真实模式默认空；演示不写真实缓存、不发真实同步。
- P-003：当日/7日（及30日）趋势真实时间轴，缺口断线，均值列有效天数；固定时区/DST正确。
- P-004：VoiceOver可读指标/单位/状态/时间，大字和减少动态效果可用；UI/真机单独验收。
- P-005：手机读取计算、Watch同步、离线和组件均需真机证据；编译不等于通过。
- P-006：基础完全离线、无账号/付费服务；日志、CI、公开仓库只含合成数据。
- P-007：每项估算可解释输入、模式、基线天数、版本、覆盖度和缺失原因。
- P-008：设置、清除和撤销按[003](003-health-and-sync.md)重算与同步。

## 表盘接入扩展（Gate 2已确认，实施中）

表盘组件按本轮STDD的watch-face-metrics、energy-complication和app-identity规格接入：电量/准备度/压力四种槽位样式，以及矩形总览；点击打开Watch对应页，双端提供系统添加说明。采用用户已确认原创图标。有效.watchface资源未准备时不提供一键安装整套表盘；具体槽位由系统表盘决定。

### Watch 首页尺寸验收细则

P-004/P-005：真实空状态和有快照的首页 SHALL 横向占满可用区域，内容不足时最小高度为页面可用高度，背景覆盖安全区域；内容超过可用高度时允许滚动，不裁切连接状态、确认操作或指标。

### 缺失原因可见

手机与Watch指标卡在显示“—”时 SHALL 同时显示具体原因，详情 SHALL 解释补充哪些输入或何时可重算：基线不足显示实际X/14有效日，缺HR/HRV/RHR、主睡眠、低覆盖、重新校准与过期分别说明。有效日不等于连续自然日，不承诺等待固定天数必然出分；空读取不推断权限被拒。真实0保留；无快照/清除/过期状态优先，演示继续明确标记。

## 解释与日内展示（metric-insights，Gate 2已确认，实施中）

只改展示，不改[002](002-scoring.md)公式、门槛与模型版本，不改HealthKit读取类型与Watch同步schema。

- 贡献分解：准备度详情显示HRV与静息心率，压力详情显示心率；每行列当前值、个人基线、差值（两者各按单位取整后相减，使三个数一致）及作用。作用按模型已截断的z值判定：≥0.5“推高准备度/推高压力”，≤−0.5“拉低准备度/降低压力”，其余“接近个人基线”；0.5只是展示分段。压力有HRV输入时另列HRV行，仅显示方向与作用（本轮不改Physiology输出，压力不保留原始HRV）；跨睡眠边界的partial桶仍用到HRV，照常列出；HR-only与运动中不列HRV行。指标无数值或已过期时不显示贡献；不显示z值或内部键名。
- 分段短句：沿用002的准备度与压力显示分段；电量无规格分段不显示。首页只描述状态，不给休息或训练建议。
- 一天的节奏：电量曲线下标出电量重放实际使用的睡眠（含小睡）与运动区间；另列压力曲线，只连接首尾相接且有值的5分钟桶，运动桶标“运动中”。缺口断线，不插值、不画0；颜色另有图例文字。电量当前值不可显示（覆盖不足、过期、校准或缺失）时不画电量曲线，改为显示原因；分析日已过去时标出报告日期与“非今天”。时间轴按固定分析时区标注。
- 睡眠详情：主睡眠阶段时间轴（清醒、REM、核心、深睡、未细分、未知，不含inBed）、效率、入睡用时、已记录清醒时长与次数、小睡列表。泳道取自完整睡眠分段与主睡眠区间的交集，主睡眠内的清醒与未知段同样显示。空值按[004](004-sleep.md)保持为空，不显示为0；没有任何睡眠分段时已记录清醒显示“—”。
- 7日趋势（long-trends已扩展为7/30日与五项指标，见下节）：准备度、睡眠时长（小时）、已观测负荷可切换；固定以报告日为终点的7个日历日，缺失日不画柱，显示有效N/7天，均值只按有效天计算；负荷为已观测值，含未完成和部分观测日，只是下界，不显示均值。日期按固定分析时区。
- 演示模式在新页面同样明确标记；VoiceOver可读指标、数值或原因与截至时间（P-004）。

## 长期趋势与近7日回顾（long-trends，Gate 2已确认，实施中）

不扩大读取窗口或类型，不改002公式与同步schema。

- 报告history为以今天为终点的35个分析日，逐日含夜间HRV（主睡眠内有效HRV至少2条的中位数）与当日静息心率；缺输入为空。各日准备度按当前读取到的61日数据重算，较早日期可用基线较短，可能仍在校准而为空。
- 个人基线区间：仅当今天的准备度使用夜间数据时提供，取值与今天准备度所用的夜间基线完全相同（前60个分析日、今天主睡眠来源、至少14个有效夜晚）。HRV为exp(median(lnHRV)±0.5×scaleH)，静息心率为median(RHR)±0.5×scaleR，即贡献分解中“接近个人基线”（|z|<0.5）的区间，按今天的基线画在整段趋势上并注明有效夜晚数。它来自本人历史，不是人群或医学正常值；也不同于准备度分数的“接近个人常态”分段。今天为日间回退或不足14个有效夜晚时不显示。
- 趋势：7/30日切换，指标为准备度、睡眠、已观测负荷、夜间HRV、静息心率；缺失日不画；HRV/静息心率在有个人基线区间时显示区间带。
- 近7日回顾：近7日（含今天）对比此前28日，项目为准备度、睡眠、夜间HRV、静息心率；近7日至少3个、此前28日至少10个有效日才给均值，两段都有才给差值；差值按显示精度先取整再相减，零不带符号；负荷不参与。只陈述差值，不给原因或建议。

## 心情记录与压力对照（mood-records，Gate 2已确认，实施中）

- 只读用户在健康或正念App自报的State of Mind（iOS 18及以上，运行时判断；iOS 17不显示卡片）；由用户在心情卡片主动连接后请求读取，未连接、无记录分别说明，空读取不推断拒绝。心情不进入评分仓库、不持久化、不同步Watch，每次刷新重新读取最近7个分析日；停止读取时清空并忘记连接请求。
- Wristlab不从心率、HRV或压力推算心情，不做相关性或因果判断；只把自报心情与同时段生理压力并列，措辞用“生理压力”，与用户自报的“有压力”标签区分。
- 配对：即时情绪取包含记录时刻的有值压力桶；该桶无值或不存在时，取记录前15分钟内结束的最近有值桶（与当前压力的时效规则一致），从不借用之后的桶；运动中的桶注明“运动中”。每日心情取当天（分析时区半开日）有值桶中位数，当天进行中注明“截至目前”。晚于报告时间的记录注明刷新后配对；没有则显示“同时段无生理压力估算”。
- 报告压力时间线保留D-6前15分钟至asOf，一天的节奏仍只画当天并标出当天的即时情绪时刻。列表为最近7个分析日、当前时刻（含）之前，去重倒序。
- 分类、标签与关联项显示固定中文名，未知值显示“未知”。演示模式使用明确标记的合成心情。
